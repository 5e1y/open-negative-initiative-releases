Your photographs render exactly as before. No stage changed shape and no setting changed value: a conversion already made comes back identical, pixel for pixel. One thing does not survive going back, and it is named first.

Presets are stored in a new form. Yours are read and converted on first launch, carrying exactly what they carried before. But a preset saved from this version is not readable by an earlier one: going back to 0.0.16 or below would show your presets carrying nothing. The photo settings themselves are untouched by this and read on any version.

A preset carries settings, not tabs

Saving a preset offered three tabs — Balance, Rendering, Detail — and each was all or nothing. It now offers the settings themselves, grouped and named as the panels name them: white balance, colour, lighting, flat-field, grade, detail. The box opens with exactly what you moved on that photograph ticked, so saving a look no longer drags every resting stage along with it.

Three settings could not be carried by any preset at all, because no tab named them: colour density, texture and the flat-field reference. They can now.

The white balance is one choice rather than two boxes, because manual and automatic write the same two settings. A preset can carry the values this photograph holds, or a method — Classic, Mids or Highs — which is measured on each photograph it is applied to rather than copied. Hovering such a preset shows the balance it will produce, not the preset without it.

Saving now happens in the app's own window instead of a system alert, and the card's colour is chosen there rather than afterwards.

Copying settings adds, and no longer strips

A copy now carries only what the source photograph actually moved. Pasting can lend a look to a frame; it can no longer take one away because the source happened to leave a stage at rest. In the same move, the conversion mode stopped travelling: pasting from a negative no longer flips a positive scan, which it did silently on a mixed roll.

Smaller things

The negative/positive selector acts on what is selected in the gallery. It used to stay bound to the last photograph opened, so it wrote to that one whatever you had selected — and stayed lit after leaving the editor when nothing was selected at all.

The gallery opens at the end of the library again, where the latest import sits.

The loupe rests at 150 % and says so. Above 1:1 the pixels are interpolated: the sharpening dose is still the one that will be written, the pixels are no longer exact.

Cropping no longer vibrates — there are no notches to feel on a frame's edges. Swiping between panels gives one tick at the point of no return instead of a run of them along the way.
