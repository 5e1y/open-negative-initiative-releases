Your photographs render exactly as before. No stage changed shape and no setting changed value: a conversion already made comes back identical, pixel for pixel. This version is about the button holding the far end of the bar.

The gallery imports where the editor exports

That button now carries the gesture that finishes the surface you are on: importing in the gallery, exporting in the editor. Each face has its own fill, so the colour states which gesture the slot is holding rather than leaving you to read the label.

Exporting from the gallery has not gone anywhere. It stays on the File menu and on the shortcut, count of targeted photographs included, and the import button says so on hover — the bar is one of four places that gesture is reachable from, never the only one.

A waiting update still outranks both faces

When a new version is waiting, that same button offers it, in orange, on either surface. The gallery is where the app lands, so a face hidden there would be hidden altogether. It still installs nothing without a click.
