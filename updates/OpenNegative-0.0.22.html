Nothing in this version changes the rendering of a photo you have already adjusted. No control moved and no default changed. The only difference is what ships alongside the application.

The source code now ships with every release

  • Every release from this one on carries its own source archive, named OpenNegative-<version>-source.zip. It holds the Swift sources, the resources, the Metal kernels, the package manifest and the Makefile: what you need to build this exact version, and nothing from my own machine.
  • Do not confuse it with the "Source code (zip)" GitHub attaches on its own. That one is an archive of the release repository, which holds binaries and an update feed, and it contains no Swift at all. The file to take is the one with -source in its name.
  • One piece is still missing, and it was missing before too. The keycap button component lives in a separate private repository, so the archive does not compile as it stands: replace it with a plain button first. That is about an hour of work, and it is spelled out on the site.

The licence has not changed, and neither has what it gives you. GPL-3.0 asks for the source that corresponds to the binary you were handed; until now that source existed but you had to ask me for it, which is not the same thing.
